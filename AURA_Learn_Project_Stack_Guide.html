🌟 AURA Learn & Career Platform

Complete Project Technology Stack & Situational Architecture Blueprint
📌 Executive Summary: AURA Learn is an interactive, multi-agent AI career and learning ecosystem featuring an AI Resume Analyzer, Live Multi-Slide Classroom, Dynamic AI Teacher Avatar, Browser Code Sandbox, and Technical Doubt Resolver. This guide details all programming languages, frontend/backend frameworks, database engines, AI models, and infrastructure tools used across the application.

1. Programming Languages Breakdown

1. TypeScript (v5.5)

  • Where Used: 100% of frontend UI code (src/), React components (.tsx), interfaces (src/types/), custom hooks (src/hooks/), Zustand stores, and Next.js serverless route handlers (src/app/api/).
  • Role: End-to-end static type safety for API requests, state updates, prompt structures, and UI prop validation.
  • Situation / Trigger: Runs during client-side user interactions, state transitions, client PDF parsing, and Next serverless API route dispatching.

2. Python (v3.11+)

  • Where Used: Backend microservice (backend/app/), multi-agent LLM engine (backend/app/agents/), FastAPI endpoints, SQLAlchemy ORM, and Celery workers.
  • Role: Powers backend AI agent workflows, prompt processing, database ORM operations, background Celery tasks, and WebSocket streaming.
  • Situation / Trigger: Executed when processing deep AI requests, querying PostgreSQL, streaming live teacher responses, and executing background jobs.

3. JavaScript (ES2023 / Node.js)

  • Where Used: Build configuration scripts (next.config.js, postcss.config.js), build tooling, and Node.js server runtime underlying Next.js.
  • Role: Executes web server initializations, SSR page pre-rendering, build optimizations, and CSS post-processing.
  • Situation / Trigger: Triggered during development (npm run dev), production build (npm run build), and SSR execution.

4. HTML5 & CSS3 / Tailwind CSS (v3.4)

  • Where Used: Component markup and custom stylesheets (src/styles/globals.css, tailwind.config.ts).
  • Role: Defines responsive visual presentation, dark glassmorphism themes, HSL visual tokens, and keyframe micro-animations.
  • Situation / Trigger: Evaluated continuously by web browser DOM layout engines across all pages.

5. SQL (PostgreSQL Dialect)

  • Where Used: Relational database schemas, DDL table migrations (backend/alembic/), and ORM query execution.
  • Role: Stores structured data for users, profile details, course progress, quiz attempt scores, and resume analysis logs.
  • Situation / Trigger: Executed during user auth, profile updates, saving course progress, logging ATS analysis, and fetching course catalogs.

4. DevOps, Infrastructure & Build Tooling

  • Docker & Docker Compose: Packages Next.js frontend, Python FastAPI backend, PostgreSQL, and Redis into unified container environments (Dockerfile, docker-compose.yml).
  • Vercel: Deploys Next.js frontend with edge routing, SSL certificates, and CI/CD preview builds (vercel.json).
  • Render Platform: Deploys Python FastAPI backend Web Service and Celery workers (render.yaml).
  • ESLint & Prettier: Enforces code style, linting standards, and automated formatting.

5. Step-by-Step Feature Situations

Feature 1: AI Resume Analysis & ATS Scoring

1. User uploads a PDF/DOCX resume file in Resume Hub UI.
2. pdfjs-dist or mammoth parses plain text client-side in browser.
3. Text is sent to Next.js API route /api/resume/analyze.
4. Gemini 2.0 Flash evaluates resume text against target job description across 5 ATS metrics.
5. Recharts renders ATS Score ring gauge and keyword matching chips.

Feature 2: Live Interactive Classroom

1. Student launches classroom course page.
2. Framer Motion renders 3D robot avatar animations.
3. Monaco Editor displays interactive code blackboard.
4. Student asks question via voice or text chat input.
5. WebSockets streams query to FastAPI backend, where Gemini/Groq agent streams live response back.

Feature 3: Dynamic AI Teacher Persona Switcher

1. Student clicks 'Switch Teacher' inside live classroom.
2. Radix UI Dialog opens without losing current slide or code state.
3. Student selects persona (Professor, Coach, Friend, Expert, Simplifier).
4. Zustand updates global persona state instantly.
5. Avatar chest emblem, eye glow color, and AI response voice tone transform dynamically.
