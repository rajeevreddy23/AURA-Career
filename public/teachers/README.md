# Classroom character sources

`reference-portrait.png` is the user's untouched Five Friends portrait. The classroom and selection cards use this file directly to preserve the characters' faces, outfits, accessories, and initials.

`studio-atlas-v1.png` is an optional generated atlas, not used by the classroom because regeneration can change identity details. Generated using built-in image generation with the original portrait as reference and transparency requested. Prompt: Remove only the pale background, floor shadows and name plates. Preserve the five original characters, poses, identities, hair, clothes, initials, shoes and accessories in the same order and scale. Keep all characters visible and separated on a transparent landscape 3:2 PNG; do not redesign or simplify them.

The live renderer uses subtle body sway and a small speech-energy-linked source-pixel mouth deformation. This is illustrated layered animation, not a rigged 3D model or phoneme-accurate lip synchronization. Reduced-motion preferences disable movement. True skeletal gestures and facial visemes require matching rigged GLB models.
